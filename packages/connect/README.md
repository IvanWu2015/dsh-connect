# dsh-connect

The **channel-agnostic core** for connecting [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (**DSH**) agents to chat platforms (Feishu / Lark and more): session binding, agent driving, streaming reply bridging, and local commands.

> Install together with a channel adapter, e.g. [dsh-connect-feishu](https://www.npmjs.com/package/dsh-connect-feishu).

## Install

```sh
dsh plugin --profile web add dsh-connect dsh-connect-feishu
```
